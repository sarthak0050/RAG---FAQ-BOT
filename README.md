# GROWW Mutual Fund FAQ Bot

Facts-only assistant for five HDFC Direct Growth mutual funds, grounded in the
official Groww fund pages. Answers are generated by Mistral from embeddings
retrieved over a local Chroma store, and every answer cites its source.

## Running locally

```bash
pip install -r requirements.txt
cp .env.example .env   # add MISTRAL_API_KEY
python3 -m code.ui
```

## Deployment

Hosted on Hugging Face Spaces. Set these Space secrets:

- `MISTRAL_API_KEY` — Mistral API key (required for answer generation)

The app reads the key from the environment at runtime.
